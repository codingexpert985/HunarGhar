\section{Backend Implementation and Traceability}
The backend is implemented with Node.js and Express and uses PostgreSQL for persistence. Authentication uses
JSON Web Tokens; passwords are stored only as bcrypt hashes (SFR-03). Real-time chat uses Socket.io, portfolio images
are stored on Cloudinary and the AI chatbot is a locally trained Multinomial Naive Bayes classifier.
